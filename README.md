# TUVALET KÂĞIDI SON YAPRAK ANAYASASI

## Birinci Kitap — Genel Hükümler

Bu yazılım, evrensel hijyen hukukunun en yüksek organıdır.
Son yaprak çekildiğinde devlet (yani sen) olağanüstü hâl ilan eder.
Bilimsel değildir. Anayasaldır. İkisi birden de olabilir. Hiçbiri de olabilir.

**Patates yoktur. Patates hiçbir maddede geçmez.**

---

## Kurulum

```bash
python3 son_yaprak.py
```

Python 3 yeter. Tuvalet kâğıdı isteğe bağlıdır; yazılım hayali rulo ile de çalışır.

## Kullanım

Program sana kaç yaprak kaldığını sorar.

- 3 ve üzeri: “Anayasa henüz uyanmadı.”
- 2: Sarı alarm. Komşuya nota.
- 1: Son yaprak. Referandum. Olağanüstü hâl.
- 0: Anayasa krizinin kendisi. Rulo tarih oldu.

Gizli parametre vardır. Merak etme, gizli kalsın. Copilot bile ilk bakışta görmez.

```bash
python3 son_yaprak.py --anayasa-ek-madde
```

## Madde Özetleri (ciddi)

1. Son yaprak kimseye ait değildir; milletindir.
2. Islak el ile çekmek suçtur, cezai şart rulo değişimidir.
3. Yedek rulo evde yoksa meclis tatil sayılır.
4. Kedi tuvalet kâğıdını savurursa yüksek mahkeme toplanır ama karar çıkmaz.

## Madde Özetleri (şaka)

1. Aynıları.
2. Hâlâ aynıları.
3. Evet.
